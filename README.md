# vqa-assistive-vision-vizwiz
Evaluation of pretrained ViLT and BLIP models on the VizWiz-VQA dataset for assistive vision, including answerability, OCR-related performance, and hallucination analysis.
Dataset: This project uses the VizWiz-VQA dataset. The dataset is not included in this repository. Please download the official VizWiz-VQA annotations and images separately before running the notebooks
